# `/art` Video Generation 프롬프트 설계

## 목표

Q&A 또는 검토된 RPG 스토리의 캐릭터 설정을 바탕으로, 외부 Video Generation 모델에 바로 전달할 수 있는 시네마틱 영상 프롬프트를 생성한다.

## 범위

- `/art`로 시작하는 `dev-guide` 질문을 영상 프롬프트 요청으로 식별한다.
- 지식 베이스의 일반 검색보다 `video-prompt-guide`를 우선 호출한다.
- 캐릭터 외형, 행동, 장면, 카메라, 조명, 영상 길이·비율, 일관성 조건을 포함하도록 모델 시스템 지침을 추가한다.
- `context`와 `evidence`에 포함된 스토리 검토 결과와 캐릭터 설정을 프롬프트 입력에 보존한다.
- 실제 영상 생성 API 호출은 이번 범위에서 제외한다.
- 기존 `planning-guide`, `art-guide`, `lore`, 직접 지식 응답의 동작은 유지한다.

## 데이터 흐름

```text
Q&A/스토리 설정 → RPG 스토리 검토 → context/evidence → /art → video-prompt-guide → Video Generation 프롬프트
```

스토리 검토는 기존 `/api/story-review` 흐름에서 수행한다. `/art`는 검토 결과를 새로 판정하지 않고, 호출자가 전달한 검토 결과와 근거를 프롬프트에 반영한다.

## 출력 원칙

모델은 근거 밖의 설정을 임의로 추가하지 않는다. 설정이 부족하면 추측하지 않고 `추가로 필요한 정보`를 표시한다. 영상 프롬프트는 캐릭터 일관성 유지 조건과 금지 조건을 포함해야 한다.

## 오류 처리

`/art` 요청인데 `video-prompt-guide`가 등록되지 않은 경우 기존 에이전트 오류 처리와 동일하게 내부 오류를 반환한다. 입력 검증과 evidence 제한은 기존 API 규칙을 따른다.
