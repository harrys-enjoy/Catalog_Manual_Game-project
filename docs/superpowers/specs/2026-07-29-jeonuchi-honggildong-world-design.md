# 전우치·홍길동 대립 세계관 확장 설계

## 목표

기존 `lore` 세계관에 전우치전과 홍길동전의 공개된 문학적 모티프를 참고한 신규 스토리라인을 추가한다. 두 인물은 선악의 양극이 아니라 자유와 질서라는 서로 다른 신념으로 활동하며, 플레이어가 어느 쪽도 절대적인 정답으로 선택하지 않도록 설계한다.

## 저작권 및 콘텐츠 원칙

- 원전의 현대 번역문, 특정 출판사의 문장, 영화·드라마 각색 대사는 복사하지 않는다.
- 새로 작성한 인물 설명, 사건, 세력, 선택지, 결말만 저장한다.
- `inspirationSources`에 모티프 수준의 참고 내용을 기록한다.
- 기존 CC0 에셋 출처인 `sourceRef`와 문학 모티프 참고 정보인 `inspirationSources`를 구분한다.

## 세계관

기존 유리별 세계관에서 시민의 신분과 기억을 관리하는 기록 체계가 특정 계층을 추방하는 사건을 일으킨다. 전우치는 도술과 변신으로 기록 체계를 폭로하고 파괴하려 하며, 홍길동은 차별 없는 공동체와 지속 가능한 제도를 건설하려 한다.

## 인물 대립

### 전우치

- 핵심 가치: 개인의 자유, 즉각적인 구원, 권위에 대한 불신
- 행동 방식: 변신, 기록 조작, 권력자 폭로, 규칙 우회
- 장점: 억압받는 개인을 빠르게 구하고 숨겨진 진실을 드러낸다.
- 위험: 질서를 무너뜨린 뒤 발생한 혼란과 책임을 충분히 통제하지 못할 수 있다.

### 홍길동

- 핵심 가치: 공동체의 평등, 지속 가능한 제도, 새로운 질서
- 행동 방식: 공동체 건설, 규칙 수립, 자원 배분, 기존 질서와의 단절
- 장점: 개인의 영웅적 행동을 제도로 확장하고 장기적인 보호 체계를 만든다.
- 위험: 평등을 유지한다는 명분으로 감시와 통제를 강화할 수 있다.

## 캠페인 구조

1. **같은 사건, 다른 해결**: 시민 기록 조작 사건을 전우치는 공개 폭로하고 홍길동은 피해자를 공동체로 이주시킨다.
2. **바람의 도둑과 새 나라의 설계자**: 전우치가 홍길동 공동체의 규칙을 공개하며 자유와 안전의 갈등이 커진다.
3. **유리별의 심장**: 시민의 기억과 신분 기록을 통제할 수 있는 장치가 발견된다.
4. **선택의 전쟁**: 플레이어가 개인의 자유, 공동체의 안정, 진실 공개, 혼란 방지 사이에서 선택한다.
5. **선악 없는 결말**: 전우치 승리, 홍길동 승리, 협력, 플레이어 독립 결말을 제공한다.

## 데이터 설계

`data/knowledge.json`의 `lore`에 다음 항목을 추가한다.

- 두 인물의 인물 카드
- 양쪽의 신념과 행동 방식
- 시민 기록 조작 사건
- 바람의 공동체
- 유리별의 심장
- 선택 축과 캠페인 장
- 네 가지 결말

각 신규 항목은 다음 메타데이터를 사용한다.

```json
{
  "originalContent": true,
  "inspirationSources": [
    "전우치전의 도술·변신·권위 풍자 모티프",
    "홍길동전의 신분 질서·공동체·이상향 모티프"
  ]
}
```

## 검색 및 UI 영향

- 기존 `lore` 모드 검색으로 인물명, 신념, 사건명, 결말을 조회한다.
- 전체 콘텐츠 보기에서 신규 항목의 원문 설명과 모티프 표기를 함께 표시한다.
- 기존 API 계약과 A2A 구조는 변경하지 않는다.

## 검증 기준

- 신규 lore 항목이 JSON으로 정상 로드된다.
- 전우치 관련 질문이 전우치 항목을 찾는다.
- 홍길동 관련 질문이 홍길동 항목을 찾는다.
- 동일 사건에 대한 두 인물의 해결 방식이 서로 다르게 반환된다.
- 신규 항목이 `originalContent: true`를 가진다.
- 모든 기존 테스트가 통과한다.
